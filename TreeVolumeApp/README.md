# Tree Volume Estimator

This Shiny app predicts the volume of a tree based on its girth using a linear regression model from the built-in R `trees` dataset.

## 📊 Features

- Select tree girth using a slider
- Toggle regression line visibility
- View predicted tree volume on a plot and as text
